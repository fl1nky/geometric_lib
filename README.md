# Geometric lib

Лабораторная работа №4 по ИСПРО

Фурлет Данил Анатольевич, M3115

Библиотека считает площадь и периметр круга, прямоугольника, квадрата и треугольника

В `test_figures.py` 24 теста на положительных, нулевых и дробных значениях

22 теста прошли, два нашли ошибку в периметре прямоугольника
Функция возвращает `a + b` вместо `2 * (a + b)`

Исходный проект: [smartiqaorg/geometric_lib](https://github.com/smartiqaorg/geometric_lib)

Вручную проверены 8 примеров, по одному на функцию
В семи ответ совпал, у периметра прямоугольника получено 7 вместо 14

## Как запустить

Нужен Python 3, unittest уже входит в него
Из папки проекта выполнить

```console
python -m unittest test_figures.py
```

Итог: запущено 24, успешно 22, FAIL 2
